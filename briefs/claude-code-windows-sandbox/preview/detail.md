# Claude Code は Windows で動く。隔離は WSL 2 だけ

**知る**（何が登場し、自分に関係するかが分かる）｜**情報紹介・未再現**

## 結論

Claude Code は Windows 10 1809 以降に直接入れられる。ただし、OS によるサンドボックスに対応するのは WSL 2 に入れた場合だけ。

## 対象の読者

社内の Windows PC で、AI のコーディング支援を試そうとしている開発の担当 — 社内の PC は Windows。導入の形（Windows に直接か、WSL 2 か）で、使える機能が変わる

## 適用の条件

- 社内の Windows PC で Claude Code を使うことを検討している
- 導入の形（Windows に直接か、WSL 2 か）をまだ決めていない

## 重要な制約

- 社内で Claude Code と WSL 2 を使えるかは未確認
- サンドボックスが何を制限するかは、まだ読んでいない

## 要点

- Windows 10 1809 以降なら、Windows に直接入れられる
- OS によるサンドボックスは WSL 2 でだけ対応
- Windows に直接入れる場合は Git for Windows が推奨

## 導入の形で、何が変わるか

- Windows に直接: サンドボックス は 非対応、Git for Windows は 推奨
- WSL 2: サンドボックス は 対応、Git for Windows は 不要
- WSL 1: サンドボックス は 非対応、Git for Windows は 不要

公式の文書の表によると、OS によるサンドボックスに対応するのは WSL 2 だけで、Windows に直接入れた場合と WSL 1 は対応していない。Git for Windows は、Windows に直接入れる場合に推奨されている（無い場合は PowerShell が使われる）。WSL では不要。

## 概要

公式の文書は、Windows での導入の形として、Windows に直接、WSL 2、WSL 1 を挙げ、それぞれのサンドボックスの対応を表で示している。導入の方法は、PowerShell のインストーラー、WinGet、npm、WSL の中での Linux 向けの方法。
