【判断する｜情報紹介・未再現】AI が書いたコードを、社内 PC のどこで動かすか

要点
・そのまま動かすと、自分の権限で届く範囲すべてに触れる
・Podman のコンテナは、通信と書き込み先を指定して絞れる
・どの隔離の方式も、社内の許可の確認が先に要る

条件・制約
・社内の Windows PC では、どの方式も動かしていない
・WSL 2 と仮想化の機能を使えるかは、社内で未確認
・コンテナに替えるだけでは、隔離は成立しない

図の内容（動かす場所で、隔離と、要る確認はどう違うか）
そのまま実行: 隔離の範囲 は なし、社内で要る確認 は なし
WSL 2 の隔離機能: 隔離の範囲 は 未確認、社内で要る確認 は WSL 2 の許可
Podman コンテナ: 隔離の範囲 は 指定した範囲、社内で要る確認 は 仮想化の許可

検証の状況: 情報紹介・未再現 — 各提供元の公式の文書を読み比べただけ。社内の Windows PC では、どの方式も動かしていない
確かめていない点: 社内で WSL 2、Hyper-V、Podman を使えるか ／ Claude Code の WSL 2 でのサンドボックスが制限する範囲（該当の文書を読んでいない） ／ Windows 上の Podman の仮想環境で、指定した制限が実際に効くか（Linux での確認は別の投稿候補 podman-isolation-verify にある）

対象: 社内の Windows PC で、AI が書いたコードを動かして試そうとしている開発の担当
